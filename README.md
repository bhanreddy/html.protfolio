# html.protfolio

This is my personal portfolio website showcasing my skills, projects, and experience as a developer. It serves as an online resume and a platform to connect with potential employers and collaborators.

## Features

- **Home Page** – Introduction and a brief overview.
- **About Me** – Details about my background, skills, and interests.
- **Projects** – A showcase of my best projects with descriptions and links.
- **Skills** – A list of technologies and tools I am proficient in.
- **Contact** – Ways to reach out to me via email or social media.

## Technologies Used

- **HTML** – Structure of the website.
- **CSS** – Styling and responsiveness.
- **JavaScript** – Enhancing interactivity.
- **VS Code** – Code editor used for development.
- **GitHub** – Version control and hosting repository.

## Installation & Usage

1. Clone the repository:
   ```sh
   https://github.com/bhanreddy/html.protfolio
   ```
2. Navigate to the project directory:
   ```sh
   cd portfolio
   ```
3. Open `index.html` in a browser to view the website.
